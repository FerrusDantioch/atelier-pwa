Atelier PWA — fichiers d'autres auteurs embarqués dans le jeu
==============================================================

Le code du jeu est © 2026 Ferrus Dantioch, sous licence CC BY-NC-ND 4.0
(voir le fichier LICENSE). Les fichiers ci-dessous ne sont pas de Ferrus
Dantioch : ils gardent leur propre licence, dont le texte complet est
fourni à côté d'eux.

Aucun de ces fichiers n'est chargé depuis internet pendant le jeu : ils sont
copiés dans le dépôt. Leurs empreintes SHA-256 (en bas de ce fichier)
permettent de vérifier qu'ils n'ont pas été modifiés ; les tests le
vérifient à chaque lancement (tests/tiers.test.js).

Pour les mettre à jour (outil de développement, jamais lancé pendant la
publication) : node outils/embarquer-tiers.mjs
